# hagane, kagami, sui

※　このプロジェクトは開発中です。

## 共通
`hagane`, `kagami`, `sui`はそれぞれModern C++ (C++26)で記述されたライブラリです。

## hagane
`hagane`は`Vulkan`をラップする低レイヤーのライブラリです。


### 目的
`VulkanHPP`はCスタイルの配列に渡す際、C++規格が定める厳密なエイリアシング規則に違反している可能性があると考えました。そのため、このライブラリでは規格に可能な限り沿った`Vulkan`のラッパーを定義しようと考え、開発に取り組みました。

### 特徴
1. **必要最小限の構成**: 今後紹介する`sui`で用いられる構造体、関数のみのラップを行っており、実用的なもののみをラップしています。このため、広大な`Vulkan`の仕様を探索しなくても良い設計となっております。
2. **エラーハンドリング**: `std::expected`等を用いたエラーハンドリングを行い、例外を使用していません。`VulkanHPP`では例外を使用するため、ユーザーの`-fno-exceptions`指定が妨げられることを考慮しました。
3. **C++的記述**: 構造体メンバーを`setter`クラスにより、直感的に操作することが可能です。Cスタイルの配列を受ける関数などはすべてラップし、`span`や`vector`を入出力とする関数を定義しました。
4. **定義動作の保証**: `#pragma once`を除き、基本的に純粋なC++規格を遵守します。`VulkanHPP`のグレーゾーンである厳密なエイリアシング規則に関する問題は発生しません。

## kagami
`kagami`は`GLFW`のラップする低レイヤーのライブラリです。

### 目的
`sui`が`hagane`のC++スタイルの操作をするのに対し、GLFWの直接呼び出しは全体としての単一抽象度原則に沿っておらず、これを達成するため、開発を決断しました。

### 特徴
基本的には`hagane`と同様の特徴です。マクロを使用せず、可能な限りマクロなどは列挙体やコンパイル時定数に変更するなど、型安全なModern C++としての記述に努めました。

## sui
`sui`は`hagane`及び`kagami`を使用して作られたゲームライブラリです。
開発者の以前の成果物である2Dゲームライブラリの`rin`は`OpenGL`を用いて記述されていますが、より低レイヤーでの制御を可能にするため開発を決断しました。

### 特徴
`hagane`や`kagami`と同様に、Modern C++としての記述に努めています。ただし、他にも以下のような特徴が存在します。

**null安全**: `Vulkan`は多くの型をポインタとして公開しています。これはnull安全とは言えません。本ライブラリはC++26で定義された`std::optional<T&>`部分特殊化を採用しています。これにより、nullポインタアクセスの危険を大幅に抑止できます。
